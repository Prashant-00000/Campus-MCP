# ⚠️ Simulated Results — DO NOT CITE

All files in this directory were generated by the **offline deterministic simulator** (`_simulate_response` in `agent/llm.py`), not by a real language model API.

**Why they are here:** The simulator was useful for unit-testing the evaluation harness and agent loop logic without incurring API costs. It verified that grading logic, CI computation, and CSV export all work correctly.

**Why they must not be cited:** The simulator always chooses the "right" tool because it pattern-matches on the same keyword rules the eval dataset was written against. Accuracy numbers from simulated runs are structurally circular and not predictive of real model behavior.

**What to do instead:**

```bash
# Set your real API key
export GROQ_API_KEY=your_key_here   # or OPENROUTER_API_KEY

# Run the actual 2-model benchmark
python scripts/run_eval.py

# Run the actual red team
python scripts/run_redteam.py
```

Real result CSVs will appear in `results/` (not this subdirectory).
